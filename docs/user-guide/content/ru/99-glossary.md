# Словарь {#glossary}

| Слово | Что оно значит |
|---|---|
| Встреча | Один случай, когда вы заполнили форму для пациента. |
| Форма | Набор вопросов о пациенте. |
| Раздел форм | Группа форм в списке форм. |
| Групповая сессия | Одна форма, заполненная сразу для нескольких пациентов. |
| Гость | Тот, кто пользуется приложением без входа в учётную запись. |
| Опознать позже | Записать пациента, которого пока не удаётся найти, и позже найти его на сервере. |
| Режим онлайн | Отправка на сервер всего, что вы сохраняете, сразу. |
| Локация | Место, где вы работаете. |
| Вход без подключения | Разблокировка приложения отпечатком, лицом или блокировкой экрана без интернета. |
| Список пациентов | Группа пациентов, которую вы выбираете хранить на планшете. |
| Сервер | Центральный компьютер, где хранятся данные вашей организации. |
| Единый вход | Вход с учётной записью, которую вам выдала организация, на её собственной странице. |
| Синхронизация | Отправка вашей работы на сервер и получение свежих данных. |
| Визит | Период оказания помощи, в котором может быть несколько встреч. |
