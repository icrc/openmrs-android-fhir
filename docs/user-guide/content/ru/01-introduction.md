# Введение {#introduction}

## Что делает приложение {#what-it-does}

Приложение помогает заботиться о пациентах. С его помощью вы можете:

- зарегистрировать нового пациента и найти уже известных вам пациентов;
- записать визит или заполнить форму для пациента (это **встреча**);
- заполнить одну форму сразу для нескольких пациентов (**групповая или семейная сессия**);
- отправить свою работу на центральный сервер и получить свежие данные (**синхронизация**).

Приложение хранит копию ваших пациентов **на планшете**. Поэтому можно работать без интернета. Когда есть связь, приложение отправляет то, что вы записали.

## Главные понятия простыми словами {#key-ideas}

| Слово | Что оно значит |
|---|---|
| Пациент | Человек, о котором вы заботитесь. Приложение хранит его имя, возраст, контакты и то, что вы записали. |
| Список пациентов | Группа пациентов, например «Утренний приём». Вы выбираете, какие списки хранить на планшете. |
| Локация | Место, где вы работаете. Всё, что вы записываете, сохраняется за этой локацией. |
| Форма | Набор вопросов, на которые вы отвечаете о пациенте, например шкала скрининга. |
| Встреча | Один случай, когда вы заполнили форму для пациента. |
| Визит | Период оказания помощи, в котором может быть несколько встреч. Организация решает, управляете ли вы визитами сами. |
| Синхронизация | Отправка вашей работы на сервер и получение свежих данных. |

## Что вам нужно {#what-you-need}

- Планшет с установленным приложением.
- Имя пользователя и пароль (или учётная запись единого входа) от вашей организации.
- Подключение к интернету **в первый раз**, чтобы загрузить пациентов. После этого можно работать без связи.

## Работа с приложением на планшете {#tablet-tips}

- Приложение работает в вертикальном положении и поворачивается вместе с планшетом.
- Экраны такие же, как на телефоне, только крупнее. Списки шире и читаются легче.
- Держите планшет двумя руками, когда печатаете. Клавиатура закрывает нижнюю половину экрана.
- Кнопка **?** справа вверху на большинстве экранов запускает короткий обзор этого экрана.
