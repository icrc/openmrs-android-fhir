# À propos de ce guide {#about .unnumbered}

Ce guide explique comment utiliser l'**application OpenMRS pour tablette** afin d'enregistrer des patients, de noter ce que vous faites pour eux et de protéger votre travail, même sans internet.

## À qui s'adresse ce guide {#audience .unnumbered}

Vous utilisez l'application sur le terrain ou dans une clinique. Vous savez utiliser une tablette, mais vous n'avez pas besoin de connaître l'informatique. Chaque étape est courte et ne demande qu'une seule action.

## Comment le lire {#how-to-read .unnumbered}

- Les mots en **gras** sont les mots que vous voyez à l'écran. Ils sont écrits exactement comme dans l'application, dans votre langue.
- Les numéros sur les images correspondent aux numéros des étapes.
- Un encadré qui commence par **Remarque** donne une information en plus. **Astuce** indique un moyen plus rapide. **Attention** signale quelque chose qui pourrait faire perdre votre travail ou provoquer une erreur.
- Tous les noms, numéros et lieux des images sont inventés. Ce ne sont pas de vraies personnes.

> **Remarque :** l'application peut être un peu différente dans votre organisation. Votre organisation choisit les options de connexion, les formulaires et les listes que vous voyez. Ce guide montre une configuration courante.

## Nouveautés de cette édition {#whats-new .unnumbered}

C'est la première édition du guide. Elle couvre la connexion, les patients, les formulaires, les visites, les séances de groupe, la synchronisation, l'import et l'export, les paramètres et la sécurité.
