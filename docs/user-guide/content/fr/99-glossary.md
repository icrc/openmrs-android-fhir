# Glossaire {#glossary}

| Mot | Ce que cela veut dire |
|---|---|
| Consultation | Une fois où vous avez rempli un formulaire pour un patient. |
| Formulaire | Une série de questions sur un patient. |
| Section de formulaires | Un groupe de formulaires dans la liste des formulaires. |
| Séance de groupe | Un seul formulaire rempli pour plusieurs patients à la fois. |
| Invité | Quelqu'un qui utilise l'application sans se connecter. |
| Identifier plus tard | Noter un patient que vous ne retrouvez pas encore, et le retrouver sur le serveur plus tard. |
| Mode en direct | Envoyer au serveur ce que vous enregistrez, tout de suite. |
| Lieu | L'endroit où vous travaillez. |
| Connexion hors ligne | Déverrouiller l'application avec l'empreinte, le visage ou le verrouillage de l'écran, sans internet. |
| Liste de patients | Un groupe de patients que vous choisissez de garder sur la tablette. |
| Serveur | L'ordinateur central où sont gardées les données de votre organisation. |
| Authentification unique | Se connecter avec le compte que votre organisation vous a donné, sur sa propre page. |
| Synchronisation | Envoyer votre travail au serveur et recevoir les dernières données. |
| Visite | Une période de soins qui peut contenir plusieurs consultations. |
