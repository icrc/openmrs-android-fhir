# Glossary {#glossary}

| Word | What it means |
|---|---|
| Encounter | One time you filled in a form for a patient. |
| Form | A set of questions about a patient. |
| Form section | A group of forms in the list of forms. |
| Group session | One form filled in for several patients at once. |
| Guest | Someone who uses the app without signing in. |
| Identify later | Recording a patient you cannot find yet, and finding them on the server later. |
| Live mode | Sending what you save to the server right away. |
| Location | The place where you work. |
| Offline login | Unlocking the app with fingerprint, face or screen lock, without internet. |
| Patient list | A group of patients that you choose to keep on the tablet. |
| Server | The central computer where the data of your organisation is kept. |
| Single sign-on | Signing in with the account your organisation gave you, on its own page. |
| Sync | Sending your work to the server and receiving the latest data. |
| Visit | A period of care that can hold several encounters. |
