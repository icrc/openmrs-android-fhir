# المسرد {#glossary}

| الكلمة | معناها |
|---|---|
| اللقاء | مرة واحدة ملأت فيها نموذجاً لمريض. |
| النموذج | مجموعة أسئلة عن مريض. |
| قسم النماذج | مجموعة نماذج في قائمة النماذج. |
| الجلسة الجماعية | نموذج واحد مملوء لعدة مرضى في وقت واحد. |
| الضيف | من يستخدم التطبيق بدون تسجيل الدخول. |
| التعرّف لاحقاً | تدوين مريض لا تستطيع إيجاده الآن، وإيجاده في الخادم لاحقاً. |
| الوضع المباشر | إرسال ما تحفظه إلى الخادم فوراً. |
| الموقع | المكان الذي تعمل فيه. |
| تسجيل الدخول بدون اتصال | فتح التطبيق بالبصمة أو الوجه أو قفل الشاشة، بدون إنترنت. |
| قائمة المرضى | مجموعة مرضى تختار الاحتفاظ بها على الجهاز اللوحي. |
| الخادم | الحاسوب المركزي الذي تُحفظ فيه بيانات مؤسستك. |
| تسجيل الدخول الموحّد | تسجيل الدخول بالحساب الذي أعطتك إياه مؤسستك، في صفحتها الخاصة. |
| المزامنة | إرسال عملك إلى الخادم واستلام أحدث البيانات. |
| الزيارة | فترة رعاية يمكن أن تضم عدة لقاءات. |
