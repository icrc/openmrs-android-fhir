# Glosario {#glossary}

| Palabra | Qué significa |
|---|---|
| Encuentro | Una vez que rellenó un formulario para un paciente. |
| Formulario | Una serie de preguntas sobre un paciente. |
| Sección de formularios | Un grupo de formularios en la lista de formularios. |
| Sesión de grupo | Un solo formulario rellenado para varios pacientes a la vez. |
| Invitado | Alguien que usa la aplicación sin iniciar sesión. |
| Identificar después | Anotar a un paciente que aún no puede encontrar, y encontrarlo en el servidor más tarde. |
| Modo en vivo | Enviar enseguida al servidor lo que guarda. |
| Ubicación | El lugar donde trabaja. |
| Inicio de sesión sin conexión | Desbloquear la aplicación con huella, rostro o bloqueo de pantalla, sin internet. |
| Lista de pacientes | Un grupo de pacientes que usted elige guardar en la tableta. |
| Servidor | El ordenador central donde se guardan los datos de su organización. |
| Inicio de sesión único | Iniciar sesión con la cuenta que le dio su organización, en su propia página. |
| Sincronización | Enviar su trabajo al servidor y recibir los datos más recientes. |
| Visita | Un período de atención que puede incluir varios encuentros. |
